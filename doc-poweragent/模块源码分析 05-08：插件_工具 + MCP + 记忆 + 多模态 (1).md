```Java
@Override
public Map<String, Object> execute(DispatchData dispatchData) {
    LOGGER.debug("RunPluginServiceImpl execute: Plugin execution, input parameters: {}", JSON.toJSONString(dispatchData));

    // 校验问题及早返回

    }

            filter(item -> item.getKey().equals(DYNAMIC_INPUT_KEY))
            .findFirst().orElse(null);
    Map<String, Object> startParams = buildParams(hasDynamicInput, inputModule, params);

    ChatDispatchParam chatDispatchParam = new ChatDispatchParam();
    BeanUtils.copyProperties(dispatchData, chatDispatchParam);
    chatDispatchParam.setHistories(dispatchData.getHistories());
    chatDispatchParam.setModules(modules);
    chatDispatchParam.setStartParams(startParams);

    if (split.getPluginId().equals("textEditor")) {
        return buildResponse(textEditorService.execute(chatDispatchParam), plugin);
    } else if (split.getPluginId().equals("tfSwitch")) {
        return buildResponse(tfSwitchService.execute(chatDispatchParam), plugin);
    } else if (split.getPluginId().equals("customFeedback")) {
        return buildResponse(customFeedbackService.execute(chatDispatchParam), plugin);
    } else {
        FlowContext flowContext = workFlowEngine.dispatchModules(chatDispatchParam);
        flowContext.countTotalTokens();
        return buildResponse(dispatchData, plugin, flowContext);
    }
}
```

```Java
private SplitCombinePlugin splitCombinePluginId(String id) {
    SplitCombinePlugin splitCombinePlugin = new SplitCombinePlugin();
    String[] splitRes = id.split("-");
    if (splitRes.length == 1) {
        splitCombinePlugin.setSource(PERSONAL.getValue());
        splitCombinePlugin.setPluginId(id);

        return splitCombinePlugin;
    }

    splitCombinePlugin.setSource(splitRes[0]);
    splitCombinePlugin.setPluginId(splitRes[1]);
    return splitCombinePlugin;
}

private RuntimePlugin getPluginRuntimeById(String id, SplitCombinePlugin splitCombinePlugin,
                                           DispatchData dispatchData) {
    if (splitCombinePlugin.getSource().equals(COMMUNITY.getValue())) {
        RuntimePlugin plugin = communityPluginManager.getCommunityPlugin().stream()
                .filter(item -> item.getId().equals(id))
                .findFirst().orElse(null);

        if (null == plugin) {
            throw new FlowBusinessException(AgentFlowCommonErrorCode.PLUGIN_NO_EXIST);
        }
        return plugin;
    }

    if (splitCombinePlugin.getSource().equals(PERSONAL.getValue())) {
        PluginStore store = pluginStoreService.getOne(new LambdaQueryWrapper<PluginStore>().eq(PluginStore::getPluginId, id));
        if (null == store) {
            throw new FlowBusinessException(AgentFlowCommonErrorCode.PLUGIN_NO_EXIST);
        }
        RuntimePlugin plugin = new RuntimePlugin();
        BeanUtils.copyProperties(store, plugin);
        plugin.setModules(JSONArray.parseArray(store.getModules(), PluginStoreModuleVO.class));
        plugin.setShowStatus(Boolean.TRUE);
        return plugin;
    }

    throw new FlowBusinessException(AgentFlowCommonErrorCode.PLUGIN_NO_EXIST);
}
```

**面试要点**: 插件不是简单函数调用，而是一个**递归的 WorkFlow 实例**。这意味着：

- 插件内部可以包含任意节点 \(LLM/检索/条件分支/循环\)

- 插件可以嵌套另一个插件 → WorkFlowEngine\.dispatchModules\(\) 递归

- 递归深度由 DAG 结构自然限制，不需要显式递归保护

- ★ 三个内置特殊插件 \(`textEditor` / `tfSwitch` / `customFeedback`\) 不走完整 DAG，直接分发给各自的 Service 单节点执行 —— 说明它们虽然是"插件"，但本质是轻量原子组件

- ★ `pluginId` 按 `-` split：长度==1 是个人插件，否则 `splitRes[0]=source`、`splitRes[1]=pluginId`（社区插件 id 形如 `COMMUNITY-xxx`）

- ★ `pluginDetail` 只在 `mode=="test"` 且是本团队插件时透出内部节点详情 —— 生产环境对外隐藏插件内部结构

- ★ 入口必须存在 `PLUGIN_INPUT` 节点，否则直接抛 `"Plugin error, It has no set input."`

```Java
@Override
public Map<String, Object> execute(DispatchData dispatchData) {
    HttpRequestProps requestProps = buildProps(dispatchData);
    String httpReqUrl = requestProps.getHttpReqUrl();
    if (StrUtil.isEmpty(httpReqUrl)) {
        throw new FlowBusinessException("Http url is empty");
    }
    Map<String, Object> concatVariables = new HashMap<>();
    if (dispatchData.getVariables() != null) {
        concatVariables.putAll(dispatchData.getVariables());
    }
    if (dispatchData.getParams() != null) {
        concatVariables.putAll(dispatchData.getParams());
    }
    if (requestProps.getDynamicInputKey() != null) {
        concatVariables.putAll(requestProps.getDynamicInputKey());
    }
    parseHeader(requestProps, concatVariables);
    parseParams(requestProps, concatVariables);
    parseReqUrl(requestProps, concatVariables);
    parseRequestBody(requestProps, concatVariables);
    httpReqUrl = requestProps.getHttpReqUrl();
    Map<String, String> headers = new HashMap<>();
    Map<String, Object> params = new HashMap<>();
    headers.put("Content-Type", "application/json;charset=UTF-8");
    List<PropsArrType> header = requestProps.getHttpHeader();
    if (CollUtil.isNotEmpty(header)) {
        Map<String, String> headerMap = header.stream().collect(Collectors.toMap(PropsArrType::getKey, PropsArrType::getValue));
        headers.putAll(headerMap);
    }
    HttpRequest request;
    if (requestProps.getHttpMethod().equalsIgnoreCase("GET")) {
        request = HttpUtil.createRequest(Method.GET, httpReqUrl).header(LanguageConstants.LANGUAGE_HTTP_HEADER, LocaleContextHolder.getLocale().toString());
        request.addHeaders(headers);
        params = requestProps.getHttpParams().stream().collect(Collectors.toMap(PropsArrType::getKey, PropsArrType::getValue));
        request.form(params);
    } else {
        request = HttpUtil.createRequest(Method.POST, httpReqUrl).header(LanguageConstants.LANGUAGE_HTTP_HEADER, LocaleContextHolder.getLocale().toString());
        request.addHeaders(headers);
        request.body(requestProps.getRequestBody().toString(), "application/json;charset=UTF-8");
    }
    if (requestProps.getTimeout() != null) {
        request.setConnectionTimeout(requestProps.getTimeout() * 1000);
    }
    addAuth(request, requestProps);
    int maxRetryTimes = 1;
    if (requestProps.getRetry() != null) {
        maxRetryTimes = requestProps.getRetry();
    }
    JSONObject resJson = new JSONObject();
    Map<String, Object> formatResponse = new LinkedHashMap<>();
    boolean success = false;
    String msg = "";
    for (int i = 0; i < maxRetryTimes; i++) {
        try {
            HttpResponse execute = request.execute();
            String res = execute.body();
            if (execute.isOk()) {
                if (StrUtil.isNotEmpty(res)) {
                    if (!JSONUtil.isJson(res)) {
                        JSONObject originRes = new JSONObject();
                        originRes.put("originResult", res);
                        response.setHttpResult(originRes);
                        msg = "result is not invalid json";
                        response.setErrorMsg(msg);
                        throw new FlowBusinessException(msg);
                    }
                    resJson = JSONObject.parseObject(res);
                    parseJson(formatResponse, resJson, "");
                    success = true;
                    break;
                }
            } else {
                JSONObject error = new JSONObject();
                error.put("message", "Request failed with status code " + execute.getStatus());
                error.put("status", execute.getStatus());
                error.put("result", execute.body());
                resJson.put("error", error);
                msg = error.toString();
                response.setErrorMsg(msg);
                throw new FlowBusinessException(msg);
            }
        } catch (Exception e) {
            msg = e.getMessage();
            response.setErrorMsg(msg);
            log.error("An exception occurred when calling the remote service", e);
        }
    }

    if (!success) {
        if (StrUtil.isNotEmpty(requestProps.getDefaultJsonResult())) {
            parseJson(formatResponse, JSONObject.parseObject(requestProps.getDefaultJsonResult()), "");
        } else {
            throw new FlowBusinessException(msg, response);
        }
    }

    response.setHttpResult(resJson);
    response.setFormatResponse(formatResponse);
    //output结果
    HashMap<String, Object> output = new LinkedHashMap<>();
    output.put(ModuleOutputKeyEnum.responseData.getValue(), response);
    output.putAll(formatResponse);
    return output;
}
```

```Java
private void parseJson(Map<String, Object> result, Object res, String prefix) {
    if (res instanceof JSONObject) {
        JSONObject object = (JSONObject) res;
        Set<String> keySet = object.keySet();
        keySet.forEach(k -> {
            Object o = object.get(k);
            String key = prefix + k;
            result.put(key, o);
            if (o instanceof JSONObject) {
                parseJson(result, o, key + ".");
            } else if (o instanceof JSONArray) {
                parseJson(result, o, key);
            }
        });
    } else if (res instanceof JSONArray) {
        JSONArray object = (JSONArray) res;
        for (int i = 0; i < object.size(); i++) {
            Object o = object.get(i);
            String key = prefix + "[" + i + "]";
            result.put(key, o);
            if (o instanceof JSONObject) {
                parseJson(result, o, key + ".");
            } else if (o instanceof JSONArray) {
                parseJson(result, o, key);
            }
        }
    }
}
```

```Java
            case "Bearer":
                request.bearerAuth(requestProps.getHttpAuthValue());
```

**面试要点**:

- URL/Header/Body 的 `{{variable}}` 模板变量替换：变量优先级 `variables → params → dynamicInputKey`（后者覆盖前者）

- GET 走 `request.form(params)`，POST 走 `request.body(json, "application/json")`

- ★ 响应非合法 JSON 时直接抛 `"result is not invalid json"` 异常，不会把非 JSON 文本当结果

- ★ 重试失败后兜底 `defaultJsonResult` 优先；无兜底才抛 `FlowBusinessException(msg, response)`

- ★ `timeout` 单位是秒，内部转成毫秒 `timeout * 1000`；未配置时 hutool 默认连接超时

- ★ 真实响应细节（headers/params/body）都塞进 `responseData`，供前端展示节点执行详情

- `buildProps()` 用 `switch (i.getKey())` 识别 11 个 `system_*` 系统参数，其余 key 全进 `dynamicInputKey`（动态变量）

- ★ 代码有变更时先 `pythonUpdateCode()` 上传：POST `/user/{userId}/package/{projectId}/entry`，body `{entry_code: mainCode}`

- ★ 异步分支 \(`callback_url` 非空\)：内部强制 `userId=115`（系统级），执行完由 af\-rag\-server 回调，不阻塞节点 —— 这就是长耗时 Python 任务不占工作流线程的手段

- ★ 参数按插件入口 `PLUGIN_INPUT` 节点的声明做类型转换 \(`conversionType`: STRING/NUMBER/BOOLEAN\)，类型不匹配抛"参数类型识别失败"

- ★ 返回值 `ret` 必须是合法 JSON 才扁平化 \(`parseJson`\)，非 JSON 文本视为失败

- ★ `runTime` 同时塞进 `resut` 和 `formatResponse`，下游可直接 `{{runTime}}` 引用执行耗时

```Java
    private final List<AutoAgentToolBaseTool> toolSchemaList;

    // convert: 工具 Schema 转换 (将 ToolOriginalDTO → FunctionDeclaration, 供 ADK LLM 识别)
    public JsonSerializable convert(ToolOriginalDTO toolOriginalDTO) {
        long start = System.currentTimeMillis();
        log.info("{} tool convert to Tool Schema", toolOriginalDTO.getType());
        AutoAgentToolBaseTool converter = findConverter(toolOriginalDTO.getType());
        converter.validate(toolOriginalDTO);
        try {
            JsonSerializable functionDeclaration = converter.tryInto(toolOriginalDTO);
            long end = System.currentTimeMillis();
            log.info("{} tool convert to Tool Schema, time taken: {}", toolOriginalDTO.getType(), end - start);
            return functionDeclaration;

        } catch (BusinessException e) {
            throw e;
        } catch (Exception e) {
            log.error("Tool Schema convert failed.", e);
            throw new BusinessException(AgentFlowCommonErrorCode.AUTO_AGENT_TOOL_SCHEMA_FAILED);
        }
    }

    // toolRun: 执行工具 (被 Python Agent 通过 /api/v1/tools/run 调用)
    public String toolRun(ToolCallDTO toolCallDTO) {
        long start = System.currentTimeMillis();
        String type = toolCallDTO.getType();
        log.info("call {} tool", type);
        AutoAgentToolBaseTool converter = findConverter(type);
        String result = converter.callTool(toolCallDTO);
        long end = System.currentTimeMillis();
        log.info("call {} tool , time taken: {}  result: {}", type, end - start, result);
        return result;
    }

    // ★ 工厂模式: 找到支持的转换器 ★
    private AutoAgentToolBaseTool findConverter(String type) {
        return toolSchemaList
                .stream()
                .filter(converter -> converter.supports(type))
                .findFirst()
                .orElseThrow(() -> new BusinessException(AgentFlowCommonErrorCode.AUTO_AGENT_UNSUPPORTED_TOOL));
    }
}
```



**面试要点**:

- ★ 用 `@RequiredArgsConstructor` \+ `final List<AutoAgentToolBaseTool>` 字段，让 Spring 把**所有实现类 Bean 一次性注入集合** —— 新增工具类型零改动（符合 Open\-Closed 原则）

- ★ `convert()` 的异常处理很讲究：`BusinessException` 原样抛出（业务失败不该被包装），其他异常才包装成 `AUTO_AGENT_TOOL_SCHEMA_FAILED`

- ★ `findConverter(type)` 按 `supports()` 匹配，找不到抛 `AUTO_AGENT_UNSUPPORTED_TOOL`；`AutoAgentToolContext` 自己不做工具逻辑，只做分发，是典型的**策略模式 \+ 工厂**组合

```Java
private static MCPToolRequest.MCPToolRequestBuilder getMcpToolRequestBuilder(McpServer mcpServer) {
    MCPToolRequest.MCPToolRequestBuilder builder = MCPToolRequest.builder();

    String headerStr = mcpServer.getHeaders();
    if (StringUtils.isNotBlank(headerStr)) {
        try {
            Map<String, String> headers = JsonBaseModel.getMapper().readValue(headerStr, new TypeReference<Map<String, String>>() {
            });
            if (MapUtils.isNotEmpty(headers)) {
                for (String key : headers.keySet()) {
                    headers.put(key, AesUtil.aesDecrypt(headers.get(key)));
                }
            }
            builder.headers(headers);
        } catch (Exception e) {
            throw new RuntimeException(e);
        }

    }
    Integer sseReadTimeout = mcpServer.getSseReadTimeout();
    if (Objects.nonNull(sseReadTimeout)) {
        builder.sseReadTimeout(Double.valueOf(sseReadTimeout));
    }
    if (null != mcpServer.getConnectionProtocol() && mcpServer.getConnectionProtocol().equals(2)) {
        builder.serverType("http");
    } else {
        builder.serverType("sse");
    }
    Integer timeout = mcpServer.getTimeout();
    if (Objects.nonNull(timeout)) {
        builder.timeout(Double.valueOf(timeout));
    }
    try {
        String url = AesUtil.aesDecrypt(mcpServer.getUrl());
        String endpoint = AesUtil.aesDecrypt(mcpServer.getEndpoint());
        builder.serverUrl(url + endpoint);
    } catch (Exception e) {
        throw new BusinessException(AgentFlowCommonErrorCode.MCP_AES_ERROR);
    }
    builder.id(mcpServer.getMcpId());
    return builder;
}
```

```Java
private MCPToolRequest createCallRequest(ToolCallDTO toolCallDTO) {
    // 获取id查询 mcp server 数据，获取自定义 headers 和 连接协议
    String id = toolCallDTO.getId();
    String mcpId = Arrays.stream(id.split(REGEX))
            .findFirst()
            .orElseThrow(() -> new BusinessException(AgentFlowCommonErrorCode.AUTO_AGENT_TOOL_VALIDATE_FAILED));
    McpServer mcpServer = getMcpServer(mcpId);

    return getMcpToolRequestBuilder(mcpServer)
            .toolName(toolCallDTO.getName())
            .args(toolCallDTO.getParams()).build();
```

- **4 个 Resource 类即 4 个 HTTP 接口**: `AddVector`\(POST 插入/异步批量插入\) / `QueryVector`\(POST 语义检索\) / `DeleteVector`\(DELETE 按 filters 删除\) / `UpdateVector`\(PUT 更新\+冲突检测\)。接口签名由 `@dataschema` \(voluptuous\) 声明,`Required("data_list"): All([{...}], Length(min=1))` 表示 data\_list 是非空数组且每条必填 id/memory/user\_id/chat\_id/team\_id/agent\_id/record\_id,`Optional("role", default=lambda: "user")` 为可选字段带默认值。

- **装饰器栈顺序**: `@dataschema`\(参数校验\) → `@error_handler`\(统一异常→fail 响应\) → `post`。voluptuous 校验失败由 error\_handler 兜底成业务失败响应。

- **同步 vs 异步**: `AddVector` 无 `callback_url` 走同步 `mem0_helper.add_memory`;有 `callback_url` 生成 `task_id` 后转 `tasks.add_memory_async` 异步执行,立即返回 `{"task_id": task_id}` 供回调。这是 agent 上传大段记忆时避免阻塞 HTTP 的设计。

- **多租户隔离**: `request.headers.get("Org-Code", "")` 取组织编码,作为 `org_code` 随 add\_memory 落库;QueryVector/UpdateVector 同样透传 `org_code` 到检索/更新条件,实现组织间记忆物理隔离。

- **更新即冲突检测**: `UpdateVector` 先 `get_memory_by_id` 取旧记忆,内容不变→直接更新;内容变了→更新后触发 `tasks.memory_conflict_async` 做记忆冲突检测\(判断新记忆是否与旧记忆矛盾\),异步不阻塞响应。

```Python
# af-rag-server/src/memory/scheduler.py
# 记忆遗忘(艾宾浩斯衰减) + 记忆删除(90天无召回) + 状态/权重指标上报
import hashlib
from datetime import datetime, timedelta
from src.server_api_tools.mem0_helper import Mem0Helper, VectorStatus, Calculator, Engine
from src.common.utils import formate_datetime
from src.component.server_component.LogManager import logger
from apscheduler.schedulers.background import BackgroundScheduler
from src.ops.mem0_metrics import record_memory_status_metrics, record_memory_weight_metrics, MemWeight, MemStatus, MEM_WEIGHT, MEM_STATUS
from src.settings import AGENT_PLUGIN_EXECUTE_URL

def upload_metrics():
    """状态权重上报"""
    MEM_STATUS.clear()
    MEM_WEIGHT.clear()
    mem0_helper = Mem0Helper()
    body = {"query": {"match_all": {}}}
    for data_list in mem0_helper.query_es_metadata(body=body):
        for item in data_list:
            metadata = item['_source'].get('metadata')
            if not metadata:
                continue
            record_memory_status_metrics(MemStatus(teamId=metadata.get("team_id", ""), status=str(metadata.get("status", ""))))
            record_memory_weight_metrics(MemWeight(teamId=metadata.get("team_id", ""), weightDim=str(round(metadata.get("weight", 1), 1))))

def memory_forget():
    """记忆遗忘"""
    logger.info(f"记忆遗忘刷新-开始")
    mem0_helper = Mem0Helper()
    body = {"query": {"bool": {"must_not": [{"term": {"metadata.status": {"value": 2}}}]}}}
    callback_engine = Engine()
    for data_list in mem0_helper.query_es_metadata(body=body):
        save_list = []
        forget_list = []
        for item in data_list:
            if not item['_source'].get('metadata'):
                continue
            metadata = item['_source']['metadata']
            weight, status = Calculator(metadata=metadata).ebbinghaus_decay()
            tmp = {'id': item['_id'], 'weight': weight, 'status': status, "updated_at": formate_datetime()}
            if not metadata.get('forgeted_at') and status == VectorStatus.FORGETED:
                tmp['forgeted_at'] = formate_datetime()
                tmp['cnt_recall_latest'] = 0
                forget_list.append(tmp['id'])
            elif metadata.get('forgeted_at') and status == VectorStatus.FORGETED and metadata.get('cnt_recall_latest', 0) > 0:
                day = (datetime.now() - datetime.strptime(metadata.get('forgeted_at')[:19].replace("T", ' '), "%Y-%m-%d %H:%M:%S")).days
                if day > 90:
                    tmp['forgeted_at'] = formate_datetime()
                    tmp['cnt_recall_latest'] = 0
            save_list.append(tmp)
        if forget_list:
            res = callback_engine.memory_forget(forget_list)
            if not res:
                continue
        logger.info(f"记忆遗忘刷新--")
        mem0_helper.es_udpate_bulk(save_list)
    logger.info(f"记忆遗忘刷新-完成")

def memory_delete():
    """记忆删除"""
    logger.info(f"记忆删除刷新-开始")
    mem0_helper = Mem0Helper()
    three_months_ago = formate_datetime(dt=datetime.now()-timedelta(days=30*3))
    body = {
        "query": {"bool": {
            "must": [
                {"bool": {"should": [{"range": {"metadata.cnt_recall_latest": {"lt": 1}}},
                                     {"bool": {"must_not": {"exists": {"field": "metadata.cnt_recall_latest"}}}}],
                          "minimum_should_match": 1}},
                {"range": {"metadata.forgeted_at": {"lt": three_months_ago}}}
            ],
            "must_not": [{"term": {"metadata.status": {"value": 2}}}]
        }}}
    callback_engine = Engine()
    count = 0
    for data_list in mem0_helper.query_es_metadata(body=body):
        save_list = [
            {'id': item['_id'], 'status': VectorStatus.DELETED, "updated_at": formate_datetime(), "deleted_at": formate_datetime()}
            for item in data_list
        ]
        logger.info(f"记忆删除刷新-{save_list}")
        res = callback_engine.memory_delete([x['id'] for x in save_list])
        if res:
            mem0_helper.es_udpate_bulk(save_list)
            count += len(save_list)
    logger.info(f"记忆删除刷新-完成:{count}")

def memory_scheduler():
    from src.memory.redis_lock import RedisLock
    key = "memory:scheduler:"+hashlib.md5(AGENT_PLUGIN_EXECUTE_URL.encode()).hexdigest()
    lock = RedisLock(key=key)
    if lock.acquire():
        logger.info(f"定时任务开始--{key}")
        memory_forget()
        memory_delete()
        upload_metrics()
    else:
        logger.info(f"定时任务lock--{key}")
    lock.release()

def run_memory_scheduler():
    logger.info(f"memory定时任务注册--")
    scheduler = BackgroundScheduler()
    scheduler.add_job(memory_scheduler, 'cron', day_of_week='0-6', hour=1, minute=0, second=0)
    scheduler.start()

if __name__ == "__main__":
    memory_scheduler()
```



**面试要点**:

- **调度入口**: `run_memory_scheduler()` 用 APScheduler `BackgroundScheduler` 注册 cron 任务 `day_of_week='0-6', hour=1, minute=0, second=0`\(**每天凌晨 1 点执行**\),注册后 `scheduler.start()` 常驻运行;`if __name__ == "__main__"` 分支支持单次手动执行 `memory_scheduler()`。

- **分布式互斥**: `memory_scheduler()` 内部用 `RedisLock`,key = `"memory:scheduler:" + md5(AGENT_PLUGIN_EXECUTE_URL)`。多个实例同时到点只有一个能 `acquire()` 成功,避免多副本重复清记忆;`finally` 语义上 `lock.release()` 保证释放。key 绑定 `AGENT_PLUGIN_EXECUTE_URL`\(执行服务地址\),不同环境天然不同 key。

- **每天做三件事**: `memory_forget()`\(艾宾浩斯遗忘刷新\) → `memory_delete()`\(过期删除\) → `upload_metrics()`\(状态/权重指标上报\)。

- **记忆遗忘 = 艾宾浩斯衰减**: `memory_forget()` 遍历 ES 中非删除状态\(`must_not status=2`\)的记忆,对每条调 `Calculator(metadata=metadata).ebbinghaus_decay()` 计算新 weight 和 status。首次衰减到 `VectorStatus.FORGETED` 时写入 `forgeted_at` 并把 `cnt_recall_latest` 清零,同时收集进 `forget_list` 调 `callback_engine.memory_forget()`\(回调删除向量\)。**90 天召回重置**:已遗忘但 `cnt_recall_latest > 0` 的记忆,若遗忘时间超过 90 天,重置 `forgeted_at` 并清零召回计数——即"又想起来"的记忆可以再次遗忘。

- **记忆删除 = 3 个月无召回**: `memory_delete()` 的 ES 查询命中 `cnt_recall_latest < 1`\(或字段不存在\) **且** `forgeted_at < 3 个月前` **且** 非删除状态,命中批量置为 `VectorStatus.DELETED` 并写 `deleted_at`,先回调 `callback_engine.memory_delete()` 成功后才 `es_udpate_bulk` 落库,用 `count` 累加统计本次删除条数。

- **存储是 Elasticsearch**: 读取用 `mem0_helper.query_es_metadata(body=body)`\(直接透传 ES DSL query\),批量更新用 `mem0_helper.es_udpate_bulk(save_list)`。记忆本体\(向量\+metadata\)存在 ES,不是 Milvus。

## 模块深度追问



### 插件/工具模块



<a id="q1"></a>
#### Q1: 插件和 Dify 的 Tool 有什么区别？



**核心差异: AgentFlow 的插件是完整的子 Workflow，Dify 的 Tool 是单一 Python 函数。**



```Plain Text
Dify Tool:    用户输入 → tool_function() → 返回结果  (一步)
AgentFlow 插件: 用户输入 → pluginInput → pluginHttp → pluginPython → pluginOutput (完整 DAG)
                          └── 内部递归调用 WorkFlowEngine ──┘
```



**实现原理**: `RunPluginServiceImpl.execute()` 加载插件的节点列表（JSON → `ModuleItemType` 列表）→ 找到入口节点 `pluginInput` → 注入参数 → 调用 `WorkFlowEngine.dispatchModules()` 递归执行。插件内部可以有任意节点组合——LLM 对话、知识库检索、条件分支、循环、HTTP——甚至可以再嵌套另一个插件。



**对比**:



|维度|AgentFlow 插件|Dify Tool|
|---|---|---|
|能力|完整 DAG 编排（LLM\+检索\+分支\+循环）|单一函数调用|
|嵌套|支持无限深度递归嵌套|不支持|
|复杂度|适合复杂多步操作（"先查库→判断结果→调API→格式化"）|适合简单单一操作（"查天气"、"翻译"）|
|开发方式|前端拖拽画布配置，无需编码|写 Python 函数代码|



<a id="q2"></a>
#### Q2: 五种工具类型的执行链路各有什么不同？



|工具类型|type 值|Java 执行器|调用目标|
|---|---|---|---|
|插件 \(个人/社区\)|`plugin`|`PluginTool.callTool()`|加载插件 JSON → WorkFlowEngine 递归执行|
|MCP 外部服务|`mcp`|`McpTool.callTool()`|MCP Client → JSON\-RPC → 外部 MCP Server|
|子 Workflow|`workflow`|`WorkflowTool.callTool()`|WorkFlowEngine 执行子流程|

```Plain Text
LLM System Prompt 中看到工具声明 → function_call 调用
```



**autoAgent/workflow 类型特殊处理**: 自动追加 `question` 参数（`"用户输入参数", type="STRING"`），因为 LLM 调用子 Agent 时总是需要传用户问题。



### MCP 集成模块



<a id="q4"></a>
#### Q4: MCP 和 Plugin 什么时候选哪个？



|场景|推荐|原因|
|---|---|---|
|公司内部 API（有 SDK）|Plugin|直接 HTTP 调用，延迟低|
|第三方外部服务|MCP|标准化协议，无需为每个服务写适配器|
|需要工具自动发现的场景|MCP|MCP Server `tools/list` 自动返回可用工具列表|
|复杂多步操作|Plugin（子 Workflow）|MCP Tool 是原子操作，Plugin 可以有完整流程|



**MCP 协议通信**: JSON\-RPC over SSE（服务端推送）或 stdio（子进程）。连接 MCP Server 后先 `tools/list` 获取工具列表 → 注册为 ADK FunctionDeclaration → LLM 调用时 `tools/call` 传递参数。



<a id="q5"></a>
#### Q5: MCP 工具如何注册到 Agent？



**四步**:

1. 用户在前端注册 MCP Server URL → 写入 `McpServer` 表

2. 为 AutoAgent 配置 `mcpInfoList`（勾选需要的 MCP 工具）

3. Agent 发布时 → `agentMeta.tools.mcpInfoList` 随 JSON 传给 Python

4. Python ADKExecutor 启动时遍历 `mcpInfoList` → 为每个 MCP 工具创建 `CommonTool(tool_type="mcp")` → 注册到 ADK LlmAgent

**工具 ID 格式**: `{mcpServerId}___{toolName}` 三下划线分隔，用于关联 MCP Server 和具体 Tool。



### 记忆模块



<a id="q6"></a>
#### Q6: 为什么长期记忆选 Mem0 向量检索而不是 LLM 结构化摘要？



**AgentFlow 的选择**: Mem0 向量化记忆。用户偏好以自由文本形式存储，检索时用语义匹配。



**优势**: 灵活——不需要预设话题类别，任何用户偏好都可以存储和检索。语义匹配能关联相关但不完全相同的记忆（"电池"和"续航"语义相近）。



**代价**: 记忆本体落到 ES（Mem0 的向量索引），需要额外维护遗忘/删除定时策略（scheduler\.py 每天凌晨 1 点艾宾浩斯衰减 \+ 3 个月无召回删除）。语义检索可能返回"语义相关但事实过时"的记忆（用户上个月偏好 5000mAh，这个月偏好变了但旧记忆仍被检索到）。



**如果重做，应该用 LLM 渐进式摘要**: 写 Prompt 约束"只记话题\+状态\+约束，绝对禁止记录具体答案"。优点：不需要向量库、摘要存 MySQL 按 conversation\_id 直接读、不依赖语义检索质量。缺点：不够灵活（无法跨会话关联相似话题）。



<a id="q7"></a>
#### Q7: 短期记忆和长期记忆怎么协同？



```Plain Text
每次对话请求:
1. Redis Session 加载当前 chatId 的完整对话历史（短期记忆，按 historyRound 保留最近 N 轮）
2. Mem0 语义检索与当前问题相关的长期记忆（向量匹配，取 TopK）
3. Prompt 组装顺序:
   System: [Agent 角色定义]
          [长期记忆] "用户偏好电池续航>5000mAh, 预算<4000元" ← Mem0 检索结果
          [对话历史摘要] "之前讨论了产品A和产品B的参数对比" ← Token 超限时 LLM 压缩生成
          [工具声明] function_call 列表
          [背景知识] RAG 检索结果
   User:  当前用户问题
```



### 多模态模块



<a id="q8"></a>
#### Q8: 视频理解的全链路怎么做的？



```Plain Text
用户上传视频
  → fileSwitch 判断 MIME type="video/*"
    → videoKeyframesExtract 视频抽帧
      → 调用 af-rag-server: POST /rag_algorithm/extract_frame
      → 每 N 秒抽一帧，返回帧图片列表
        → imgCompletion 逐帧理解
          → 调用多模态 LLM (GPT-4V / Claude Vision)
          → "第1帧: 产品参数表格, 第2帧: 电池容量5000mAh..."
            → chatNode 综合所有帧的理解结果
              → LLM: "根据视频内容，产品电池容量为5000mAh..."
```



**与纯文本 RAG 的区别**: 视频理解是多步链式处理——先抽帧再逐帧理解再综合。不是单一 LLM 调用，而是一个小 Workflow。



<a id="q9"></a>
#### Q9: AI 生成的多模态文件怎么返回给前端？



**fileInfos 透传链路**:



```Plain Text
imageGenerate 节点执行
  → 调用 DALL-E / Stable Diffusion API
  → 返回 {fileInfos: [{fileName: "架构图.png", fileUrl: "https://s3.../xxx.png"}],
            answer: "已为您生成以下文件：架构图.png"}

Python ADKExecutor.fill_custom_metadata():
  → 从工具返回的 result JSON 中提取 fileInfos
  → 设置 event.custom_metadata["fileInfos"] = fileInfos
  → 从 result 中移除 fileInfos（不重复序列化）

SSE 推送: event: plugin
          data: {..., "custom_metadata": {"fileInfos": [...]}}

前端渲染: 根据文件类型渲染 <img> / <video> / <audio>
```



**与纯文本回复的区别**: 纯文本回复通过 `answerText` 字段 → SSE ANSWER 事件推送。多模态文件通过 `fileInfos` 字段 → SSE plugin 事件（带 `custom_metadata`）推送。前端根据事件类型区分渲染方式。
