```Java
// 第 60 行（原文逐字）
public FlowContext dispatchModules(ChatDispatchParam chatDispatchParam) {
    // 1、过滤节点，获取到所有可执行节点
    List<RunningModuleItemType> runningModules = loadModules(chatDispatchParam);
    chatDispatchParam.setRunningModules(runningModules);
    // 使用 map 形式，赋值 flowProduceObject 的 moduleItemTypeMap
    FlowContext flowContext;
    flowContext = isConcurrencyExecute(chatDispatchParam)
            ? new FlowContextBuilder().buildExecutor(runningModules)
            : new FlowContextBuilder().build(runningModules);

    dealGlobalVariable(flowContext, chatDispatchParam.getVariables());
    dealSessionVariable(flowContext, chatDispatchParam.getSessionVariable());

    // 2、找到流程入口节点
    List<RunningModuleItemType> initModules = initRunningModuleType(runningModules);
    moduleInput(initModules, chatDispatchParam.getStartParams());

    if (!isConcurrencyExecute(chatDispatchParam)) {
        checkModulesCanRunSync(initModules, flowContext, chatDispatchParam);
    } else {
        checkModulesCanRun(initModules, flowContext, chatDispatchParam);
        // 线程池销毁
        flowContext.tryDestroy();
    }

    return flowContext;
}
```

```Java
private void checkModulesCanRunSync(List<RunningModuleItemType> modules, FlowContext flowContext,
                                    ChatDispatchParam chatDispatchParam) {
    for (RunningModuleItemType moduleItemType : modules) {
        // 检查 module input 是否全部满足
        if (moduleCanRun(moduleItemType)) {
            ModuleStatusVO statusVO = new ModuleStatusVO();
            statusVO.setModuleName(moduleItemType.getName());
            statusVO.setModuleId(moduleItemType.getModuleId());
            try {
                moduleItemType.setStartTime(System.currentTimeMillis());
                moduleInput(moduleItemType, flowContext.getSwitchMap());
                if (chatDispatchParam.getStream() && chatDispatchParam.getModuleStatus()) {
                    statusVO.setStatus(1);
                    SSEUtils.pubMsg(chatDispatchParam.getReqId(), SseResponseEventEnum.MODULESTATUS.getValue(), JSONObject.toJSONString(statusVO));
                }
                Map<String, Object> response = moduleRun(moduleItemType, chatDispatchParam, flowContext);
                //设置执行详情信息
                List<ChatHistoryItemResType> chatResponse = chatResponseBuild(flowContext,
                        moduleItemType, response);
                //链路监控，发送sse消息
                if (chatDispatchParam.getStream() && chatDispatchParam.getModuleStatus()) {
                    statusVO.setStatus(2);
                    statusVO.setDetails(chatResponse);
                    SSEUtils.pubMsg(chatDispatchParam.getReqId(), SseResponseEventEnum.MODULESTATUS.getValue(),
                            JSONObject.toJSONString(statusVO));
                }

                // 处理返回值，赋值子节点，同时完成递归
                List<RunningModuleItemType> nextRunModules = moduleOutput(moduleItemType, response, flowContext, chatDispatchParam);
                if (CollectionUtils.isEmpty(nextRunModules)) {
                    continue;
                }

                checkModulesCanRunSync(nextRunModules, flowContext, chatDispatchParam);
            } catch (FlowBusinessException ex) {
                LOGGER.error("WorkFlowEngine checkModulesCanRun: An exception occurred in the workflow engine--single step execution control, input parameters: {}",
                        JSON.toJSONString(moduleItemType));
                LOGGER.error(ex.getMessage(), ex);

                flowExceptionMsgPush(flowContext, chatDispatchParam, statusVO, moduleItemType, ex);
            } catch (Exception e) {
                LOGGER.error("WorkFlowEngine checkModulesCanRun: An exception occurred in the workflow engine--single step execution control, input parameters: {}",
                        JSON.toJSONString(moduleItemType));
                LOGGER.error(e.getMessage(), e);
                exceptionMsgPush(flowContext, chatDispatchParam, statusVO, moduleItemType, e);
            }
        }
    }
}
```

**面试要点**: 真实的 SSE 推送不是伪代码 `{moduleName, status:1}`，而是 `ModuleStatusVO` 序列化成 JSON 字符串 \+ `SseResponseEventEnum.MODULESTATUS` 事件类型。`chatDispatchParam.getStream() && chatDispatchParam.getModuleStatus()` 双开关控制是否推送。异常区分 `FlowBusinessException`（业务异常）和 `Exception`（系统异常），分别走 `flowExceptionMsgPush` / `exceptionMsgPush`。递归结构 = DAG 深度优先遍历：节点执行完 → `moduleOutput` 找全部下游 → 递归自身。

**面试要点**: 递归结构是 DAG 执行的核心。每个节点执行完成后，通过 `moduleOutput` 找到所有下游节点，然后递归调用自己。这不是简单的链式调用，而是一个**拓扑排序 \+ 深度优先**的 DAG 遍历。

### **2\.4 并发执行: checkModulesCanRun\(\)**

```Java
// 第 196 行（原文逐字）─── 线程池并发模式
private void checkModulesCanRun(List<RunningModuleItemType> modules, FlowContext flowContext,
                                ChatDispatchParam chatDispatchParam) {
    int executeCount = 0;

    CountDownLatch countDownLatch = new CountDownLatch(modules.size());

    // 提交任务
    for (RunningModuleItemType moduleItemType : modules) {
        // 检查 module input 是否全部满足
        if (moduleCanRun(moduleItemType)) {
            executeCount++;
            try {
                flowContext.getCompletionService().submit(() -> {
                    // switch remove 防止重复执行
                    ModuleStatusVO statusVO = new ModuleStatusVO();
                    statusVO.setModuleName(moduleItemType.getName());
                    statusVO.setModuleId(moduleItemType.getModuleId());

                    try {
                        moduleItemType.setStartTime(System.currentTimeMillis());
                        moduleInput(moduleItemType, flowContext.getSwitchMap());
                        if (chatDispatchParam.getStream() && chatDispatchParam.getModuleStatus()) {
                            statusVO.setStatus(1);
                            SSEUtils.pubMsg(chatDispatchParam.getReqId(), SseResponseEventEnum.MODULESTATUS.getValue(), JSONObject.toJSONString(statusVO));
                        }
                        Map<String, Object> map = new HashMap<>(4);
                        map.put("module", moduleItemType);
                        Map<String, Object> response = moduleRun(moduleItemType, chatDispatchParam, flowContext);
                        map.put("response", response);
                        //设置执行详情信息
                        List<ChatHistoryItemResType> chatResponse = chatResponseBuild(flowContext,
                                moduleItemType, response);
                        //链路监控，发送sse消息
                        if (chatDispatchParam.getStream() && chatDispatchParam.getModuleStatus()) {
                            statusVO.setStatus(2);
                            statusVO.setDetails(chatResponse);
                            SSEUtils.pubMsg(chatDispatchParam.getReqId(), SseResponseEventEnum.MODULESTATUS.getValue(), JSONObject.toJSONString(statusVO));
                        }
                        return map;
                    } catch (FlowBusinessException ex) {
                        LOGGER.error("WorkFlowEngine checkModulesCanRun: An exception occurred in the workflow engine--single step execution control, input parameters: {}",
                                JSON.toJSONString(moduleItemType));
                        LOGGER.error(ex.getMessage(), ex);
                        flowExceptionMsgPush(flowContext, chatDispatchParam, statusVO, moduleItemType, ex);
                        return null;
                    } catch (Exception e) {
                        LOGGER.error("WorkFlowEngine checkModulesCanRun: An exception occurred in the workflow engine--single step execution control, input parameters: {}",
                                JSON.toJSONString(moduleItemType));
                        LOGGER.error(e.getMessage(), e);
                        exceptionMsgPush(flowContext, chatDispatchParam, statusVO, moduleItemType, e);
                        return null;
                    } finally {
                        countDownLatch.countDown();
                    }
                });
            } catch (Exception e) {
                LOGGER.error("WorkFlowEngine checkModulesCanRun: Failed to add thread task: chatId: {}",
                        chatDispatchParam.getChatId());
                LOGGER.error(e.getMessage(), e);
                countDownLatch.countDown();
                executeCount = 0;
            }
        } else {
            countDownLatch.countDown();
        }
    }

    try {
        countDownLatch.await();
    } catch (InterruptedException e) {
        LOGGER.error("WorkFlowEngine checkModulesCanRun: Failed to parse countDownLatch: chatId: {}",
                chatDispatchParam.getChatId());
        LOGGER.error(e.getMessage(), e);
    }

    // 执行后续
    for (int i = 0; i < executeCount; i++) {
        try {
            Map<String, Object> map = flowContext.getCompletionService().take().get();
            if (null == map) {
                continue;
            }
            RunningModuleItemType moduleItemType = (RunningModuleItemType) map.get("module");
            Map<String, Object> response = (Map<String, Object>) map.get("response");

            // 处理返回值，赋值子节点，同时完成递归
            List<RunningModuleItemType> nextRunModules = moduleOutput(moduleItemType, response, flowContext, chatDispatchParam);
            if (CollectionUtils.isEmpty(nextRunModules)) {
                continue;
            }

            checkModulesCanRun(nextRunModules, flowContext, chatDispatchParam);
        } catch (Exception e) {
            LOGGER.error("WorkFlowEngine checkModulesCanRun: An exception occurred in the workflow engine--overall execution, input parameters: {}",
                    JSON.toJSONString(modules));
            LOGGER.error(e.getMessage(), e);
        }
    }
}
```

**面试要点**:

- `executeCount` 只统计真正提交到线程池的节点数（`moduleCanRun` 为 true 且 submit 成功）；`CountDownLatch(modules.size())` 对未提交/提交失败/执行完成的节点都 `countDown`，保证 `await()` 不会死等

- 线程任务返回的不是 response 本身，而是 `map{"module","response"}` 双字段；`executeCount` 记录提交数，后续 `take()` 正好取 `executeCount` 次，null 结果（异常返回）跳过

- `finally { countDownLatch.countDown() }` 是防死锁关键

- 异常时 `executeCount = 0` 重置：若 submit 本身抛异常，后续 take 循环直接跳过

- `CompletionService.take()` 按完成顺序返回，先完成的节点先找下游，不等最慢的

**面试要点**:

- `CountDownLatch` 确保所有并行节点完成后才进入下一批

- `CompletionService` 按完成顺序取结果（非提交顺序），先完成的节点优先找下游

- `finally` 中 `countDown()` 确保异常也不死锁

- 同级节点并行 → 下游节点递归 → 又遇同级并行 → 形成**分级并行 \+ 拓扑递归**

```Java
private Map<String, Object> moduleRun(RunningModuleItemType module, ChatDispatchParam chatDispatchParam,
                                      FlowContext flowContext) {
    // 获取要执行的module的信息
    String nodeType = module.getFlowType();
    ModuleService moduleService = moduleFactory.getService(FlowNodeTypeEnum.getType(nodeType));
    if (moduleService == null) {
        throw new FlowBusinessException("No action registered for node type: " + nodeType);
    }

    // 组装执行参数，主要是input相关的内容
    DispatchData dispatchData = new DispatchData();
    BeanUtil.copyProperties(chatDispatchParam, dispatchData);
    Map<String, Object> params = transParam(module.getInputs());

    // 组装历史消息等公共参数
    dispatchData.setParams(params);
    dispatchData.setModuleInput(module.getInputs());
    dispatchData.setModuleOutput(module.getOutputs());
    dispatchData.setModuleName(module.getName());
    dispatchData.setModuleType(nodeType);
    dispatchData.setModuleId(module.getModuleId());
    dispatchData.setModules(chatDispatchParam.getModules());
    dispatchData.setRunningModules(chatDispatchParam.getRunningModules());
    dispatchData.setGlobalVariables(flowContext.getGlobalVariables());


    // 考虑单节点失败异常情况：单步重试/整体重试/中断执行
    Map<String, Object> map = moduleService.executeWithTimeout(dispatchData);
    map.put("stepInputs", params);
    return map;
}
```

**面试要点**: `BeanUtil.copyProperties(chatDispatchParam, dispatchData)` 把请求参数整体拷给执行数据；随后 `setModuleInput/Output`（输入输出定义）、`setModuleName/Type/Id`（节点身份）、`setModules/RunningModules`（全图\+可执行节点引用）、`setGlobalVariables`（全局变量池）逐个装配。`transParam` 把 input 列表拍平成 key\-value Map，作为 `stepInputs` 挂回返回值，供 `moduleOutput` 读取 `userChatInput` 等通用字段。`executeWithTimeout` 是超时\+重试的统一入口。

### **2\.6 超时 \+ 重试: ModuleService\.executeWithTimeout\(\)**

```Java
// ModuleService.java 第 25 行（原文逐字）─── 接口默认方法
default Map<String, Object> executeWithTimeout(DispatchData dispatchData) {
    Map<String, Object> param = dispatchData.getParams();
    if (null != param.get("maxRuntime") && 0 < (int)param.get("maxRuntime")) {
        Map<String, Object> result = new HashMap<>();

        // 采用超时设置
        int maxRuntime = (int)param.get("maxRuntime");
        int retryTime = (null == param.get("retryTime") || (int)param.get("retryTime") < 1)
                ? 1 : (int)param.get("retryTime");
        retryTime = Math.min(retryTime, 3);
        boolean status = Boolean.FALSE;

        ExecutorService executorService = FlowThreadPoolUtil.getSingleExecutor();

        for (int i = 0; i < retryTime; i++) {
            Future<Map<String, Object>> future = executorService.submit(()
                    -> execute(dispatchData));
            try {
                // 设置超时时间
                result = future.get(maxRuntime, TimeUnit.SECONDS);
                status = Boolean.TRUE;
                break;
            } catch (TimeoutException e) {
                future.cancel(Boolean.FALSE); // 取消任务
            } catch (InterruptedException | ExecutionException e) {
                future.cancel(Boolean.FALSE); // 取消任务
                executorService.shutdown();
                throw new FlowBusinessException(e.getMessage());
            } catch (Exception e) {
                future.cancel(Boolean.FALSE); // 取消任务
                executorService.shutdown();
                throw e;
            }
        }
        executorService.shutdown();

        if (!status) {
            ChatHistoryItemResType responseData = new ChatHistoryItemResType();
            responseData.setPrice(0.0);
            result.put("responseData", responseData);
            if (null != param.get("moduleDefaultOutput")
                    && !CollectionUtils.isEmpty((Map<String, Object>) param.get("moduleDefaultOutput")))
            result.putAll((Map<String, Object>) param.get("moduleDefaultOutput"));
        }
        return result;
    } else {
        return execute(dispatchData);
    }
}
```

**面试要点**:

- `result`/`status` 必须在循环前声明——`TimeoutException` 分支 `break` 不会执行，`result` 需要可见于循环外

- `retryTime` 默认 1（null 或 \<1），再 `Math.min(retryTime, 3)` 封顶 3 次；`InterruptedException | ExecutionException` 与 `TimeoutException` 是同一 catch 兄弟链，前两者直接抛 `FlowBusinessException`

- 每次重试用独立的 `FlowThreadPoolUtil.getSingleExecutor()`（单任务线程池），结束后 `shutdown()` 回收

- 兜底有两个动作：① 塞一个空 `responseData`（price=0\.0）避免下游 NPE；② `putAll(moduleDefaultOutput)` 合并用户配置的默认输出

**面试要点**: `maxRuntime` 秒级超时，最多重试 3 次，每次都 `future.cancel(false)` 取消旧任务。失败后返回 `moduleDefaultOutput` 兜底值，不会中断整个流程。

### **2\.7 节点输出处理: moduleOutput\(\)**

```Java
// 第 362 行（原文逐字）─── 最关键的数据流转方法 (118 行)
private List<RunningModuleItemType> moduleOutput(RunningModuleItemType module, Map<String, Object> response,
                                                 FlowContext flowContext, ChatDispatchParam chatDispatchParam) {
    // 1、赋值通用变量
    RunningFlowNodeOutputItemType outputItemType = null;
    RunningFlowNodeOutputItemType outputConnect = null;
    for (RunningFlowNodeOutputItemType item : module.getOutputs()) {
        if (item.getKey().equals("userChatInput")) {
            outputItemType = item;
        }
        if (item.getKey().equals("outputConnect")) {
            outputConnect = item;
        }
    }
    Map<String, Object> inputParams = (Map<String, Object>) response.get("stepInputs");
    boolean hasUserChatInputTarget = outputItemType != null;
    //&& !CollectionUtils.isEmpty(outputItemType.getTargets());
    response.put("finish", Boolean.TRUE);
    response.put("userChatInput", hasUserChatInputTarget
            ? inputParams.get("userChatInput").toString() : null);

    // 1、赋值全局变量 ：answerText、chatResponse
    pushStore(module, response, flowContext);

    if (module.getFlowType().equals(ABILITY.getValue())) {
        return Collections.emptyList();
    } else if (module.getFlowType().equals(LOOP_BREAK.getValue())) {
        flowContext.setLoopEndCondition((String) response.get("condition"));
        return Collections.emptyList();
    }

    List<RunningModuleItemType> nextRunModules = new ArrayList<>();
    Map<String, RunningModuleItemType> set = new HashMap<>();

    if (null != outputConnect) {
        for (RunningFlowNodeOutputItemType outputItem : module.getOutputs()) {
            if (outputItem.getKey().equals("outputConnect")
                    || null == response.get(outputItem.getKey())) {
                continue;
            }

            outputItem.setValue(response.get(outputItem.getKey()));
            if (null != outputItem.getGlobalKey()) {
                flowContext.getGlobalVariables().put(outputItem.getGlobalKey(), outputItem.getValue());
            }

            if (CollectionUtils.isEmpty(outputConnect.getEdges())) {
                continue;
            }
            for (String edge : outputConnect.getEdges()) {
                RunningModuleItemType targetModule = flowContext.getModuleItemTypeMap().get(edge);
                if (null == targetModule) {
                    continue;
                }

                if (null == set.get(targetModule.getModuleId())) {
                    nextRunModules.add(targetModule);
                    set.put(targetModule.getModuleId(), targetModule);
                }
            }
        }
        moduleInputGlobal(nextRunModules, flowContext);
    } else {
        boolean single = false;
        for (RunningFlowNodeOutputItemType outputItem : module.getOutputs()) {
            if (null == response.get(outputItem.getKey())) {
                continue;
            }

            outputItem.setValue(response.get(outputItem.getKey()));
            if (null != outputItem.getGlobalKey()) {
                flowContext.getGlobalVariables().put(outputItem.getGlobalKey(), outputItem.getValue());
            }

            if (!CollectionUtils.isEmpty(outputItem.getEdges())) {
                single = true;
                for (String edge : outputItem.getEdges()) {
                    RunningModuleItemType targetModule = flowContext.getModuleItemTypeMap().get(edge);
                    if (null == targetModule) {
                        continue;
                    }

                    if (null == set.get(targetModule.getModuleId())) {
                        nextRunModules.add(targetModule);
                        set.put(targetModule.getModuleId(), targetModule);
                    }
                }
                moduleInputGlobal(nextRunModules, flowContext);
            } else if (!CollectionUtils.isEmpty(outputItem.getTargets())) {
                for (FlowNodeOutputTargetItemType target : outputItem.getTargets()) {
                    Map<String, Object> outputValue = new HashMap<>();
                    RunningModuleItemType targetModule = flowContext.getModuleItemTypeMap().get(target.getModuleId());
                    if (null == targetModule) {
                        continue;
                    }

                    if (null == set.get(targetModule.getModuleId())) {
                        nextRunModules.add(targetModule);
                        set.put(targetModule.getModuleId(), targetModule);
                    }
                    if (null != target.getKey()) {
                        outputValue.put(target.getKey(), outputItem.getValue());
                    }
                    moduleInput(targetModule, outputValue);
                }
            }
        }
        if (single) {
            moduleInputGlobal(nextRunModules, flowContext);
        }
    }

    // 无后续节点，递归结束
    if (CollectionUtils.isEmpty(nextRunModules)) {
        return null;
    }

    return nextRunModules;
}
```

**面试要点**: `moduleOutput` 是 DAG 数据流转的核心，先做两件通用赋值：

- **通用变量**: 扫描 outputs 找 `userChatInput` 和 `outputConnect` 两个特殊 key；`response.put("finish", true)`、`response.put("userChatInput", ...)` 给所有下游统一注入

- **全局变量**: `pushStore()` 累积 `chatAnswerText`（仅 answerText 标记的节点/ANSWER\_NODE/ABILITY 才追加）

然后三种下游连接方式（`set` 用 HashMap 去重，避免一个下游节点被多条边重复加入）:

1. **outputConnect 分支**（`outputConnect != null`）: 遍历所有 outputItem，凡是有实际 response 值的都按 `outputConnect.getEdges()` 连到下游，最后 `moduleInputGlobal` 统一注入全局变量到下游 input

2. **edges 分支**（outputItem 有 edges）: 走 outputItem 自己的 edges 找下游 \+ `moduleInputGlobal` 注入全局变量

3. **targets 分支**（outputItem 有 targets）: 按 `target.getKey()` 精确赋值下游特定 input，`moduleInput(targetModule, outputValue)`

两个提前返回: `ABILITY`（子 Agent 调用后不再找下游）、`LOOP_BREAK`（写 `loopEndCondition` 终止循环）。最后 `nextRunModules` 为空返回 `null`，递归自然结束。

**面试要点**: `moduleOutput` 是 DAG 数据流转的核心，支持三种下游连接方式:

1. **edges**: 粗糙连接 → 把下游节点加入 nextRunModules

2. **targets**: 精确连接 → 按 `target.key` 赋值下游节点的特定 input

3. **globalKey**: 跨路径连接 → 写入全局变量池，任何后续节点均可通过 `globalKey` 引用

```Java
public List<RunningModuleItemType> convertToRunningModules(List<ModuleItemType> modules, Map<String, Object> variables) {
    List<ModuleItemType> collect = modules.stream()
            .filter(module -> !module.getFlowType().equals(USER_GUIDE.getValue()) || !module.getFlowType().equals(NOTE_NODE.getValue()))
            .collect(Collectors.toList());
    List<RunningModuleItemType> res = new ArrayList<>(collect.size());
    collect.forEach(a -> {
        RunningModuleItemType item = new RunningModuleItemType();
        item.setModuleId(a.getModuleId());
```
